# The userspace stack and the kernel-module build set. Every name here was
# verified to resolve against the image's enabled repositories (negativo17
# fedora-multimedia plus Fedora) in the pinned base on 2026-11-14; the commands
# and their output are in docs/research/2026-11-14-nvidia-module-signing.md and
# docs/research/2026-11-14-nvidia-variant-build.md.
#
# The module path is decided (#72): `akmod-nvidia` ships source under
# /usr/src/akmods and `akmods` compiles it against the image's newest installed
# kernel. The resulting module is unsigned, which is the documented exception in
# docs/research/2026-11-14-nvidia-module-path-decision.md, so this variant makes
# no Secure Boot claim and needs a per-machine MOK enrollment (#40).
#
# build/common.sh installs this file only when Containerfile.nvidia names it in
# PACKAGE_MANIFEST_EXTRA. The shared image does not read it.

# headers for the kernel the image boots. kernel-devel-matched requires
# kernel-core and kernel-devel at its own version, which pins the pair to one
# version; build/common.sh fails the build when the installed devel does not
# match the newest installed kernel.
