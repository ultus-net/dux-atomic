# Changelog

## Unreleased

- Bound the publish signing and attestation retries. Run 42827200322 pushed `:sha-133fa04`, then sat in "Sign the digest and attest the SBOM" for 51 minutes until the 60-minute job timeout killed it, and GitHub kept no log for the timed-out job, so nothing could say which call hung. Each attempt now runs under a five-minute `timeout --kill-after`, and each command has a ten-minute wall-clock budget over at most five attempts, so the step is bounded even when every call hangs, and a stall ends with a message instead of a killed job. The two verification calls are single-shot and capped at three minutes each. The step emits the pushed digest as a check-run annotation before signing. `tests/test-static.sh` fails if the cap, the budget, the failure return, the attempt counter, or the notice ordering is removed, and it runs the helper itself at scaled constants to prove a hang is cut.
- Add the Steam gaming layer (#17). `manifests/packages-common.txt` gains a `# Gaming` group with `steam`, `gamescope`, `mangohud`, and `steam-devices`. `steam-1.0.0.87-4.fc45` comes from the already-enabled `fedora-multimedia` repository, and `gamescope 3.16.29-1.fc45`, `mangohud 0.8.3~rc1-4.fc45`, and `steam-devices 1.0.0.101^git20260625.22ec85e-2.fc45` come from Fedora. `tests/verify-image.sh` asserts that every one of them and `mesa-vulkan-drivers.i686` are installed in the built image. `dnf5 install --assumeno steam` measures 249 packages, 226 MiB downloaded, and 779 MiB installed, with 4 upgrades and 5 replacements. `docs/applications.md` records the delivery split, the Steam licence note, and the measured cost, and `docs/known-gaps.md` records that no game has been launched from a built image. Lutris follows in a later commit after the gaming dogfood, and the NVIDIA variant follows too.
- Shrink the SBOM so the attestation fits Rekor's request limit. Run 42810574149 signed the digest, then failed `cosign attest` six times over fifteen minutes. The attestation body was about 86 MB, because syft records 86111 file entries, 85109 of them reached by RPM `CONTAINS` relationships, and Rekor's public instance answers 502 above a request-body limit that a replay placed between 16 and 32 MB. `build/sbom-packages-only.jq` strips the file inventory, the relationships that point at it, and the package verification codes that covered it, so the uploaded and attested document is 6508304 bytes instead of 64181348, still carries 2906 packages, and has no dangling reference. `tests/test-static.sh` runs the filter against a fixture and fails if a file survives or a package still claims analysis. `docs/known-gaps.md` records that every package reports `filesAnalyzed: false`.

- Retry the publish signature and attestation. Run 42799652955 signed the digest, then failed the attestation on a Rekor 502, and `publish` now retries `cosign sign` and `cosign attest` separately, up to six attempts each with a 30s pause that doubles to 480s, about fifteen minutes per command, and the job timeout rises to 60 minutes to hold that budget. A failed attestation never signs the digest twice. The run fails only after the last attempt, and `tests/test-static.sh` asserts the bounded loop so a revert cannot pass the static gate. The retry stays for genuine 5xx and network failures; the 502 in these runs came from the body size, which the first entry above fixes. A later entry caps each attempt and each command's budget, so the six-attempt, 480s figure no longer describes the step.

- Make the hosted boot test deterministic. The first hosted `image` run (42778269701) never printed the greeter session line and timed out at 900s; a local TCG boot showed the same silent console with a live greeter session (`loginctl` listed `c1` and `niri` was running). - Add the CI/CD pipeline. `.github/workflows/ci.yml` runs `tests/lint.sh` (shell syntax, shellcheck, actionlint, `tests/test-static.sh`, hadolint) on every PR. The `image` job holds only `contents: read` because it runs PR code: it builds the image, runs `tests/verify-image.sh` (`bootc container lint` and `systemd-analyze verify`), emits an SPDX SBOM with a digest-pinned syft container that scans a flattened rootfs and writes the report to a file (the docker-archive scan needed more than 8 GB, and the former action buffered the report in memory until the Node heap died), builds the qcow2 with bootc-image-builder, runs `boot-smoke.sh` on QEMU TCG, then scans with a digest-pinned trivy container in report-only mode until the base findings are triaged (#3). A separate `publish` job runs only on `main`, holds the write token and OIDC identity, and runs no repository code: it pushes `:sha-<commit>`, signs the digest with cosign keyless OIDC, attests the SBOM, and verifies the signature and the attestation. A manual promotion dispatch moves `:latest` and asserts the registry digest. Every action is pinned by commit SHA, main runs are never cancelled, and artifacts carry a retention. Add `.github/CODEOWNERS`, a PR template, `justfile` local parity against the same lint script, `LICENSE` (MIT), and Dependabot. `boot-smoke.sh` falls back to TCG when `/dev/kvm` is absent and finds Ubuntu's OVMF paths. `make-disk.sh` passes the SELinux label only on an SELinux host.
